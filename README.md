## 🛠️ Tech Stack & Architecture

- **Frontend Core:** React 19, Vite, Tailwind CSS v4, Motion (Framer Motion)
- **3D Graphics & Visuals:** Three.js, React Three Fiber, Drei, Cobe (interactive 3D globe)
- **Performance:** Image format fallbacks (WebP & PNG), responsive layouts, throttled scroll observers, chunk-load error boundaries
- **Deployment:** Vercel CI/CD with automated GitHub workflow integration
